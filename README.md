# Credit-card-fraud-detection-using-ANN
The project focused to build an ANN-based model to accurately detect credit card fraud and  improve fraud detection by handling imbalances in classes through preprocessing and balancing  techniques SMOTE. 
The dataset used originates from the Kaggle (Credit Card Fraud Detection, 2018), which is named as Credit Card Fraud Detection dataset, comprising 284,807 transactions made by European cardholders in September 2013. 
Dataset Link: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
